# Contexto operativo

Esta carpeta reúne el contexto estable necesario para trabajar en ReportesTarjetasApp sin depender de conversaciones previas.

## Lectura inicial

1. `AGENTS.md`
2. `context/PROYECTO_CONTEXT.md`
3. `context/ESTADO_ACTUAL.md`
4. `context/GIT_TRABAJO.md`
5. Las decisiones aplicables en `context/decisiones/`

## Reglas de mantenimiento

- Documentar hechos verificados, no supuestos.
- Actualizar `ESTADO_ACTUAL.md` cuando cambie la base del proyecto.
- Registrar decisiones arquitectónicas importantes como ADR.
- No guardar secretos, credenciales, URLs privadas ni datos de clientes.
- Mantener el proyecto productivo original en modo de solo lectura.
